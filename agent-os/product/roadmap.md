# Product Roadmap

1. [x] Serviço Automático 07h — Conectar fontes prioritárias (Workplace, Health Check, 1-1s, Feedbacks) aplicando normalização e configurando rotina interna que execute a atualização diária pontualmente às 07h. `M`
2. [x] Botão de Atualização On-Demand — Expor ação manual (com confirmação) e exibir timestamp da última sincronização em área comum do sistema. `S`
3. [x] Admin Console Inicial — Criar tela administrativa com autenticação simples e formulários para configurar links e parâmetros por relatório. `M`
4. [x] Configurador por Tema — Permitir múltiplas seções de configuração (Trabalho Híbrido, Health Check, 1-1s etc.) com validação e preview dos dados. `M`
5. [x] Menu Gestores + Navegação Contextual — Implementar menu lateral/topo para acessar sessões detalhadas por tema, com filtros e breadcrumbs. `S`
6. [ ] Configuração de Arquivos por Tema — Melhorar interface de configuração de arquivos SharePoint, começando por Trabalho Híbrido (2 arquivos Excel obrigatórios). `S`
7. [ ] Dashboards Detalhados para Gestores — Construir painéis com tabelas, KPIs e insights (alertas) para cada tema priorizado. `L`
8. [ ] GAV Rubix Dashboards Rotativos — Criar telas otimizadas para monitores/TV, cada uma com URL dedicada e componente de slideshow/manual override. `M`
9. [ ] Catálogo Dinâmico de Relatórios — Permitir cadastro de novos temas, reutilizando componentes de configuração, ingestão e visualização. `L`

> Notes
> - Sequência prioriza infraestrutura de dados e governança antes das visões.
> - Item 6 (Configuração de Arquivos) é pré-requisito para itens 7-9.
> - Itens 7-9 dependem da consolidação configurável entregue nos passos anteriores.
